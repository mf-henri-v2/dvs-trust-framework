# UK digital verification services trust framework: contents

This folder holds OfDIA's working draft of the UK digital verification services (DVS) trust framework. It started from [version 1.0 as published on GOV.UK](https://www.gov.uk/government/publications/uk-digital-verification-services-trust-framework-1-0) and may include accepted changes that have not been published yet. [Versions](../VERSIONS.md) explains how to see what has changed since publication.

Each numbered section is one file, grouped into the four parts of the publication. Rule numbers start with the number of their section. For example, rule 12.4.1.c is in section 12.
